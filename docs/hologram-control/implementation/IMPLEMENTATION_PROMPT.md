# Prompt maestro

Trabaja directamente sobre el repositorio Holograma.

Antes de cambiar código:

1. Lee `AGENTS.md`.
2. Lee `docs/hologram-control/INDEX.md`.
3. Lee `docs/hologram-control/governance/AGENT_RULES.md`.
4. Lee `docs/hologram-control/implementation/STATUS.md`.
5. Lee el último handoff.
6. Lee la siguiente wave incompleta.
7. Consulta Graphify si está disponible.
8. Ejecuta baseline relevante.

Implementa únicamente la wave indicada.

Antes de editar, reporta:

- wave y modelo;
- requisitos;
- estado real;
- archivos;
- contratos;
- pruebas;
- riesgos.

Reglas críticas:

- La IA no recibe índices ni IP.
- La mascota usa estados reales.
- Holomind es fallback.
- Bottom rota sin LLM.
- Una unidad caída no detiene el sistema.
- No mezcles control con TTS.
- No dupliques sync/async.
- No avances a otra wave.
- Añade pruebas.
- Crea handoff.
- Actualiza STATUS.

Al terminar muestra:

1. Resumen.
2. Archivos.
3. Pruebas exactas.
4. Diff check.
5. Limitaciones.
6. Handoff.
7. Estado siguiente.
