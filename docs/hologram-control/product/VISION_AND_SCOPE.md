# Visión y alcance

## Visión

Holomind debe acompañar visualmente su conversación mediante tres ventiladores:

- mascota;
- identidad;
- promociones.

El operador configura el significado de los índices. El sistema selecciona automáticamente durante la conversación.

## Objetivos v1

- Tres conexiones persistentes.
- Estados de mascota.
- Identidades configurables.
- Rotación continua.
- Contenido contextual.
- MediaRouter híbrido.
- API administrativa.
- UI administrativa.
- Simulador.
- Compatibilidad.
- Operación sin hardware.

## No objetivos

- Subir videos al fan.
- Lip-sync.
- Splicing entre unidades.
- Render 3D.
- Entrenar modelos.
- Reescribir proveedores LLM.
- Control de brillo o velocidad por IA.
- Detectar automáticamente playlists físicas.
