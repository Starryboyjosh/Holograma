# Requisitos

## Funcionales

- **HC-FR-001:** administrar top, center y bottom.
- **HC-FR-002:** top usa estados reales.
- **HC-FR-003:** center usa Holomind por defecto.
- **HC-FR-004:** incluir UNEV e ITEE.
- **HC-FR-005:** bottom rota continuamente.
- **HC-FR-006:** bottom acepta foco contextual.
- **HC-FR-007:** catálogo editable.
- **HC-FR-008:** routing híbrido.
- **HC-FR-009:** todo control usa ScenePlan.
- **HC-FR-010:** integrar sync y async.
- **HC-FR-011:** API administrativa.
- **HC-FR-012:** UI administrativa.
- **HC-FR-013:** identificación física.
- **HC-FR-014:** simulador.
- **HC-FR-015:** compatibilidad heredada.

## No funcionales

- **HC-NFR-001:** aislamiento por unidad.
- **HC-NFR-002:** fail-soft.
- **HC-NFR-003:** concurrencia segura.
- **HC-NFR-004:** persistencia atómica.
- **HC-NFR-005:** cero fuga de control.
- **HC-NFR-006:** extensibilidad por catálogo.
- **HC-NFR-007:** operación local.
- **HC-NFR-008:** observabilidad.
- **HC-NFR-009:** shutdown limpio.
- **HC-NFR-010:** timeout de router.
- **HC-NFR-011:** accesibilidad básica.
