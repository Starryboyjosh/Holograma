02
Vista general

¿Qué es Holograma UNEV?

Es un asistente multimodal que combina conversación por IA, voz, cámara y una interfaz web. Puede funcionar solo como software o controlar un ventilador holográfico físico.

03
Preparación

Antes de encender

Necesario

  • Computadora con Windows o Linux.
  • Python 3.11 o superior.
  • Node.js 20.19 o superior para construir la interfaz.
  • Micrófono y altavoces para usar voz.
  • Internet y una API key, o un modelo local con Ollama.

Opcional

  • Cámara USB o integrada.
  • Ventilador holográfico MISSYOU.
  • Router o conexión Wi‑Fi directa al ventilador.
  • Clips MP4 preparados y cargados.

Comprobación física rápida

1

Deje espacio libre

El ventilador debe estar firme, sin cables ni personas cerca de las aspas.

2

Conecte audio y cámara

El sistema operativo debe reconocerlos antes de iniciar Holograma.

3

Decida el tipo de IA

Nube: más fácil, requiere clave. Local: sin clave, requiere Ollama y más recursos.

4

Prepare la red del ventilador

Use su Wi‑Fi directo o la IP reservada en el router del montaje.

Seguridad: nunca toque el ventilador mientras gira. Corte la alimentación antes de moverlo, limpiarlo o revisar la tarjeta.
04
Primera instalación

Windows

Realice esta página una sola vez. Abra la carpeta del proyecto, haga clic en la barra de dirección, escriba powershell y presione Enter.

1

Instale los requisitos

Python 3.11+ marcando “Add Python to PATH”, y Node.js 20.19+.

2

Copie y pegue el bloque completo

Espere a que cada instalación termine. Puede tardar varios minutos.

py -m venv .venv .\.venv\Scripts\python.exe -m pip install --upgrade pip setuptools wheel .\.venv\Scripts\pip.exe install -r requirements.txt cd frontend npm install npm run build cd .. Copy-Item .env.example .env -ErrorAction SilentlyContinue
Cuando termine, debe existir una carpeta .venv y otra llamada static. La carpeta static contiene la interfaz ya construida.

Prueba inicial

.\.venv\Scripts\python.exe main.py

Cuando aparezca la dirección del servidor, abra http://127.0.0.1:8000 en Chrome, Edge o Firefox. Para detenerlo, vuelva a PowerShell y presione Ctrl + C.

05
Primera instalación

Linux

Abra Terminal dentro de la carpeta del proyecto. En la mayoría de escritorios puede hacer clic derecho sobre la carpeta y elegir “Abrir en terminal”.

1

Instale los requisitos

Python 3.11+, el módulo venv y Node.js 20.19+.

2

Copie y pegue el bloque

Si el sistema solicita la contraseña, escríbala aunque no aparezcan caracteres.

python3 -m venv .venv ./.venv/bin/python -m pip install --upgrade pip setuptools wheel ./.venv/bin/pip install -r requirements.txt cd frontend npm install npm run build cd .. cp -n .env.example .env chmod +x scripts/run_web.sh scripts/Holograma.sh
La instalación de audio, cámara o aceleración puede requerir paquetes propios de su distribución. Primero ejecute el diagnóstico de la página 17; así sabrá exactamente qué componente falta.

Prueba inicial

./.venv/bin/python main.py

Abra http://127.0.0.1:8000. Detenga el servidor con Ctrl + C.

07
Uso diario

Encender en Windows

1

Abra la carpeta del proyecto

No mueva ni elimine la carpeta .venv.

2

Ejecute el lanzador

Haga doble clic en scripts\run_web.cmd.

3

Espere el mensaje del servidor

La ventana negra debe permanecer abierta.

4

Abra la interfaz

Visite http://127.0.0.1:8000.

Iniciando Servidor Web...
INFO: Application startup complete.
INFO: Uvicorn running on
http://127.0.0.1:8000

Listo para usar.
Firewall: si Windows pregunta, permita Python en redes privadas. No es necesario abrir acceso público.

Apagado normal

Cierre la pestaña del navegador, vuelva a la ventana negra y presione Ctrl + C. Espere el mensaje de apagado antes de cerrar la ventana.

08
Uso diario

Encender en Linux

1

Abra una terminal en el proyecto

La terminal debe mostrar la carpeta donde están main.py y scripts.

2

Ejecute el lanzador

Copie el comando siguiente.

./scripts/run_web.sh
3

Abra la interfaz

Visite http://127.0.0.1:8000 en el navegador.

4

Mantenga la terminal abierta

El servidor se detiene si la cierra.

“Permiso denegado”

chmod +x scripts/run_web.sh ./scripts/run_web.sh

Apagado

Presione Ctrl + C en la terminal y espere el cierre limpio.

Si el navegador no se abre solo, escriba la dirección manualmente. “127.0.0.1” significa que la aplicación está en la misma computadora.

Conversación

Hablar o escribir

🎙
Toca para hablar
1

Pulse el círculo

Espere a que aparezca “Te escucho”.

2

Hable con claridad

Use frases cortas y deje de hablar al terminar.

3

Espere la respuesta

El estado pasará por escuchando, pensando y hablando.

Escribir una consulta

⌨

Abra el cuadro de texto

Pulse el botón de teclado, escriba la pregunta y elija “Enviar”. También puede usar Saludar, Carreras, Admisiones o Ayuda.

Qué significan los estados

● En espera

Listo para una nueva pregunta.

● Escuchando

El micrófono está capturando.

● Pensando

La IA prepara la respuesta.

● Hablando

La voz se está reproduciendo.

Si no desea voz, escriba las consultas. El sistema sigue funcionando sin micrófono.

13
Contenido del ventilador

Prepare los clips

Formato visual

  • MP4 para video o JPG para imagen.
  • Fondo negro obligatorio.
  • Una unidad: relación 1:1.
  • Tres unidades: relación 5:12.

Orden recomendado

  1. Espera / idle
  2. Escuchando
  3. Hablando
  4. Pensando

El índice depende del orden de carga, no del nombre del archivo.

Duración sugerida

Hasta 30 segundos por clip, en bucle.

Cambio automático

La IA selecciona el clip según su estado.

Para tres ventiladores unidos, envíe el comando a la unidad host del montaje. La propagación debe validarse en el hardware real.
14
Administración

Ajustes importantes

🧠

Proveedor y modelo

Elija la IA, escriba la clave si corresponde y pruebe la conexión.

🎤

Whisper

Small o Medium local; large-v3-turbo usa Groq.

👁

YOLO

Active o desactive visión y ajuste el intervalo de detección.

🔊

Voz Piper

Seleccione voz y use “Probar Voz” antes del evento.

🌓

Apariencia

Claro, oscuro o según el sistema.

🌀

Conexión física

IP, puerto, conectar, reconectar o desconectar.

Regla de operación: cambie una cosa a la vez, pulse “Probar conexión” cuando exista y después “Guardar y aplicar cambios”.

Antes de una exposición

  • Pruebe una pregunta por voz.
  • Compruebe que se escucha la respuesta.
  • Encienda la cámara y verifique el contador.
  • Confirme que el ventilador cambia de clip.
  • Deje la terminal abierta y visible para el operador.

16
Ayuda rápida

Problemas comunes

!

La página no abre

Compruebe que la terminal sigue abierta y que muestra http://127.0.0.1:8000. Reinicie el lanzador.

↻

Dice “Reconectando”

Espere unos segundos. Si continúa, recargue la página y revise los errores de la terminal.

🎙

No escucha

Verifique permisos del micrófono, el dispositivo de entrada del sistema y el modelo Whisper.

📷

No aparece la cámara

Pruebe otro índice de cámara, cierre otras aplicaciones que la usen y confirme los permisos.

🧠

La IA no responde

Abra Configuración y use “Probar conexión”. Revise proveedor, modelo, Internet o servicio Ollama.

🌀

El ventilador no cambia

Confirme Third party control, Wi‑Fi, IP, puerto 50200 y el indicador Conectado.

Ejecute el diagnóstico

Windows
.\.venv\Scripts\python.exe scripts\diagnose_hologram.py
Linux
./.venv/bin/python scripts/diagnose_hologram.py

Busque las líneas [FAIL]. Ellas indican el componente que necesita atención.
